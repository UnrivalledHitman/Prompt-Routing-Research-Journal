\section*{Highlights}

\begin{itemize}
  \item Manual escalation costs up to 13x the cheapest configuration that
        would have answered
  \item Most of that escalation tax is stickiness, not the price of failed
        attempts
  \item Below 8B, a larger model buys accuracy more cheaply than turning
        reasoning on
  \item One-shot routers beat costly habits but need a cheap recovery rule
        to beat a climb
  \item Energy per token rises 6.6x from 0.6B to 8B, so token counts
        misprice routing
\end{itemize}
